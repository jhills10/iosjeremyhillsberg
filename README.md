# iOS Resource Library

An educational library for humans and coding agents learning to build iOS apps. Start with the [index](INDEX.md), read the [engineering foundations](docs/ios-foundations.md), and follow [AGENTS.md](AGENTS.md) when contributing with an agent.

## Purpose

Explain iOS engineering through original writing, small illustrative examples, and links to public primary sources. Each resource should help a reader understand a decision, its tradeoffs, and how to verify the result.

This repository is public. Never import Grid Health source code, secrets, customer data, or private business information. This restriction includes excerpts, screenshots, logs, generated summaries, and adaptations of private material. Anonymization does not make private source material acceptable here.

## Contribute

1. Choose a focused topic from the [index](INDEX.md).
2. Write original educational content using synthetic examples. Cite public sources for externally sourced claims and check version-sensitive guidance against current documentation.
3. Update the index and run `python3 scripts/check_publication.py`.
4. Follow [CONTRIBUTING.md](CONTRIBUTING.md) and complete the pull request checklist.

## Publication safeguards

The [publication policy](PUBLICATION.md) defines the review process. CI checks the tracked files for common credential patterns and unexpected file types. These checks are a safety net; human review of provenance and content is still required.
